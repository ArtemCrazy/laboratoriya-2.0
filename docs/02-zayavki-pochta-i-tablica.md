# Заявки: почта и Google-таблица

Заявка с сайта всегда сохраняется в панели управления — это основной канал.
Письмо и таблица идут дополнительно, и их сбой заявку не теряет.

## 1. Почему письма попадали в спам

Почта домена `cblabconference.ru` обслуживается Яндексом (запись MX ведёт на
`mx.yandex.net`). Сайт стоит на хостинге reg.ru. Письмо, отправленное сервером
хостинга от адреса домена, для спам-фильтра выглядит как подделка: адрес свой,
сервер чужой, подписи нет.

Дополнительно у домена **две записи SPF** сразу:

```
v=spf1 redirect=_spf.yandex.net
v=spf1 include:spf.unisender.com ~all
```

По стандарту допускается только одна. Две дают ошибку `permerror`, и проверка
SPF не проходит вообще ни для одного письма с домена — включая рассылки.

Записи DMARC у домена нет.

### Что нужно поправить в DNS домена

Одна запись SPF вместо двух:

```
v=spf1 include:_spf.yandex.net include:spf.unisender.com ~all
```

И запись DMARC — тип TXT, имя `_dmarc`:

```
v=DMARC1; p=none; rua=mailto:info@cblabconference.ru
```

DKIM у домена уже есть, селектор `mail` — его настроил Яндекс.

## 2. Отправка писем через ящик домена

Настраивается в панели: раздел «Заявки», галочка «Отправлять письма через
почтовый ящик». Тогда сайт не отправляет письмо сам, а отдаёт его SMTP-серверу
Яндекса от имени ящика. Письмо подписывается DKIM и проходит проверки.

Что ввести:

- сервер `smtp.yandex.ru`, порт `465`
- ящик — например `info@cblabconference.ru`
- пароль приложения из Яндекс 360

**Пароль приложения**, а не обычный пароль от почты. Заводится в профиле
Яндекс ID: «Безопасность» → «Пароли приложений» → «Почта». Обычный пароль
Яндекс для SMTP не принимает.

Кнопка «Проверить каналы» отправляет тестовую заявку на указанный адрес и
показывает результат по каждому каналу.

## 3. Дубль заявок в Google-таблицу

Таблица — независимый канал: даже если письмо не дойдёт, строка появится.

### Как завести

1. Создать таблицу на Google Диске.
2. Меню «Расширения» → «Apps Script».
3. Вставить код ниже, сохранить.
4. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение».
   - «Запускать от имени»: от своего имени
   - «У кого есть доступ»: у всех
5. Скопировать ссылку вида `https://script.google.com/macros/s/…/exec`.
6. Вставить её в панели сайта, раздел «Заявки», и сохранить.

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const lead = JSON.parse(e.postData.contents);

  const columns = [
    ['createdAt', 'Дата'],
    ['type', 'Сценарий'],
    ['name', 'Имя и фамилия'],
    ['company', 'Компания'],
    ['role', 'Должность'],
    ['email', 'Email'],
    ['phone', 'Телефон'],
    ['tariff', 'Пакет участия'],
    ['people', 'Участников'],
    ['format', 'Формат'],
    ['promo', 'Промокод'],
    ['comment', 'Комментарий'],
    ['id', 'Номер заявки'],
  ];

  // Шапку добавляем один раз, при первой заявке
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(columns.map(function (c) { return c[1]; }));
    sheet.getRange(1, 1, 1, columns.length).setFontWeight('bold');
    sheet.setFrozenRows(1);
  }

  sheet.appendRow(columns.map(function (c) {
    const value = lead[c[0]] || '';
    return c[0] === 'createdAt' ? new Date(value) : value;
  }));

  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

Проверить связку можно той же кнопкой «Проверить каналы» — в таблице появится
строка «Проверка связи».
